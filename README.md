
# Compilateur pédagogique en Java

**Description**  
Ce projet est un **compilateur pédagogique développé en Java**, basé sur le livre *Essentials of Compilation*.  
L’objectif est de construire progressivement un compilateur complet, en allant de concepts simples à des fonctionnalités plus avancées, tout en expérimentant la **construction d’infrastructures de parsing et d’analyse syntaxique**.  

Le projet se concentre pour l’instant sur la création d’une **base modulaire de parsing**, permettant de développer ensuite des compilateurs pour différents langages proposés dans le livre.  

---

## Fonctionnalités (en cours)

- Infrastructure de **parsing modulaire** pour différents langages  
- Analyse lexicale et syntaxique de base  
- Structures et classes pour représenter les **arbres syntaxiques abstraits (AST)**  
- Préparation pour l’implémentation de transformations et de génération de code  
- Suivi de concepts de compilation enseignés dans *Essentials of Compilation*  

> À ce stade, l’infrastructure de parsing est en cours de développement et constitue la base du compilateur pédagogique.
